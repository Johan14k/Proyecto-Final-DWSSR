# Proyecto-Final-DWSSR

*Proyecto de la materia de Desarrollo Web SSC.*

---

## 🌟 Competencias

✅ **Competencias previas**
Desarrolla aplicaciones web utilizando ES6, HTML y CSS, y utiliza herramientas de software que facilitan el desarrollo de aplicaciones web modernas.

🚀 **Competencias a desarrollar**
Diseñar, construir y evaluar un prototipo que monitoree en tiempo real el funcionamiento de un motor pequeño y detecte automáticamente comportamientos anómalos a partir de varias mediciones, integrando sensores, un microcontrolador, comunicación MQTT, un backend en Express, una interfaz web y persistencia en MongoDB.

## 🗃️ Tipos de Commits

| Icono | Tipo | Descripción |
| :---: | :--- | :--- |
| ✨ | **feat** | Nueva característica o funcionalidad en el proyecto. |
| 🐛 | **fix** | Corrección de un error o *bug*. |
| 📝 | **docs** | Cambios exclusivos en la documentación (ej. actualizar el *README*). |
| 🎨 | **style** | Cambios de formato que no afectan la ejecución (espacios, indentación). |
| ♻️ | **refactor** | Reestructuración de código que no añade funciones ni arregla errores. |
| ⚡ | **perf** | Mejoras de rendimiento o de tiempos de carga. |
| ✅ | **test** | Creación, actualización o corrección de pruebas. |
| 🔧 | **chore** | Tareas de mantenimiento, actualización de dependencias o configuración. |
| ⏪ | **revert** | Revierte el código a un estado de un commit anterior. |
